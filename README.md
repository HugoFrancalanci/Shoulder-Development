# Shoulder_Dev

A MATLAB toolbox for shoulder biomechanics analysis, developed as part of several
research projects within the B-Lab (Biomechanics and Translational Research
in Surgery Group, University of Geneva).

## About

This repository grows alongside the research. Methods, validations, and
coding conventions get refined as the protocol and patient data demand it.
Some parts are stable and validated, others are still experimental.

## Development

Traceability first. Every method added rests on a clear scientific
reference and a validation step before it joins the main pipeline.

Backward compatibility by default. Patients and sessions already processed
should never break silently when the code evolves.

A tool that explains itself. Console reports and diagnostics are part of
the code, not an afterthought.
